FIRST ADMIN SETUP
- On a fresh installation, the login gate checks whether a user-facing Admin exists.
- If none exists, First Admin Setup appears automatically.
- If startup is slow, use the Create Admin button on the login screen.
- Create your own username and password. No default Admin password is shipped.

RESET SYSTEM
- Click Reset System.
- Choose Yes/OK to continue or No/Cancel to stop.
- After Yes, type YES exactly in the final confirmation.
- No account password is requested for this reset confirmation.
- The reset clears local application data and returns to First Admin Setup.
- It does not format the device or delete the application source.

FILE CHECKUP
- App Health Center > File Checkup is OFF by default.
- It is read-only and checks project files for accessibility/readability.
- If enabled, Skip Checkup stops the operation and turns the option OFF again.
- The checkup never executes, deletes or rewrites project files.

FEATURES
- Windows-style desktop, Start/App Menu, taskbar and independent app windows.
- HCR AI Agent, AI model/runtime tools, voice/assistant modules where supported.
- HCR Store, Feedback & Support, GitHub update repository, configurable 24×7 Feedback & Support.
- Security Center, App Lock, Secure Locker, audit-oriented administration.
- Developer Toolkit, Text Tools, Regex, Color, CSV, JSON, Markdown, editor and network tools.

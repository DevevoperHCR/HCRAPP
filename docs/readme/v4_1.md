# DeveloperHCR v4.2 — Windows-style desktop beta

## First launch
1. Run `launcher.py` (or double-click `start_windows.bat`).
2. The startup screen shows only the DeveloperHCR logo, fake loading animation and a 5-second countdown. **Skip** opens Login immediately.
3. The browser login contains only: logo, Username, Password, Start, Login Troubleshoot, README.txt and a compact Remember me checkbox. Owner password reset is not offered. No role text or New User button is shown.
4. The single Owner account is preconfigured in the packaged database. Owner/Admin role is detected automatically after successful login. The browser never pre-fills an Owner name.
5. On a fresh database, `launcher.py` asks only for the Admin username and password. It does not create a second Owner.

## Login errors
- Missing username/password are shown directly below Start.
- Unknown username and wrong password are reported explicitly.
- Disabled/pending accounts are reported explicitly.
- Owner/Admin login does not wait for desktop initialization.

## Desktop
- Windows-style taskbar and HCR launcher.
- Launcher supports touch/pointer clicks and opens apps into real windows.
- Windows can be moved, resized, minimized, maximized and closed.
- Landscape and portrait desktop modes are both supported. Fullscreen is available on PC and Android browsers.
- Owner has full feature access; Admin has its separate role and dashboard.
- Settings includes display orientation, wallpaper/theme, UI controls, account and developer/environment tools.
- Custom cursor and virtual mouse controls are available from the desktop/settings layer.

## HCR Store
- Built-in DeveloperHCR apps remain free and are bundled with the release.
- External Store products can have prices such as ₹1, ₹10 and ₹100.
- A paid Store request asks the user for a reason before opening the configured WhatsApp group.
- Payment is not falsely marked as completed by the local app; Owner/Admin confirmation is required.

## WhatsApp support
The release has the configured HCR WhatsApp group in Settings/Store subscription flows.

## Password reset
Use the local Windows console only:
- Owner: `Owner password reset is disabled; the existing Owner credential is preserved.`
- Admin: `python launcher.py --reset-admin-password`

Passwords are never displayed by the browser and are stored as salted PBKDF2 hashes.

## Windows run
```text
pip install -r requirements.txt
python launcher.py
```
Or double-click:
```text
start_windows.bat
```

## AI runtimes
AI runtime monitoring continues after login. Configure Ollama or a supported GGUF runtime in **AI Models**. The desktop can show configured/running AI runtimes without blocking login.

## Important
- External Store packages must be explicitly installed and HTTPS validated.
- EXE/Wine actions remain permission-gated.
- Unsupported platform features report their actual availability.
- The application does not claim real payment verification until a real payment provider/backend is connected.

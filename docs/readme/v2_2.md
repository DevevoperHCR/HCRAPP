# DeveloperHCR v2.3.0-beta

This release extends v2.1 without removing the existing modular feature set.

### Release highlights
- Preconfigured Owner account from owner-supplied credentials.
- Account credential management with salted PBKDF2 password storage.
- Case-insensitive unique usernames.
- WhatsApp-assisted subscription request and manual Owner/Admin approval.
- Full Admin user list and subscription request management.
- Owner subscription request management.
- Local SQLite migration for `subscription_requests`.

### Payment note
No real payment gateway is included. A paid plan becomes active only after an Owner/Admin approval action. WhatsApp is a communication/confirmation channel, not automatic proof of payment.

### WhatsApp note
The project files did not contain a real WhatsApp group URL, so this release leaves the setting configurable instead of inventing a destination.

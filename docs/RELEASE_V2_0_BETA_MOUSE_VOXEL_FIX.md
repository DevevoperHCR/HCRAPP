# v2.0 BETA — Mouse, AI, Support & Voxel Update

## Fixed
- Fixed `support is not defined` in Feedback & Support.
- Removed WhatsApp-dependent support UI; Feedback & Support is now 24×7 local-first with the GitHub repository link.
- Fixed virtual mouse activation: cursor overlay is created when needed, remains pointer-safe, and left-click uses the target element's native `.click()` path.
- Added a clear Virtual Mouse panel with movement, left/right click and scroll controls.

## AI improvements
- Added a simple **Command Center** with fewer controls, quick commands and a microphone button.
- Added **Search** to the normal AI Chat toolbar. It opens the entered query in the system browser.
- HCR AI Agent remains available for voice, safe commands, local AI runtimes and screen/training controls.

## Games
- Added **HCR Voxel World**, an original block-building sandbox inspired by the voxel-building genre.
- Supports movement, block placement/removal, keyboard controls and touch controls.
- It does not use Minecraft code, textures, names, or proprietary assets.

## Release policy
- Existing apps and features are preserved.
- No passwords, tokens, runtime databases, or user data are bundled.
- This is still a BETA release; hardware-specific microphone, browser and pointer behavior can vary by Android/PC browser.

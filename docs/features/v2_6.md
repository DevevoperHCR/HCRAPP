# DeveloperHCR v2.6.0-beta

## Startup
- 5-second visible startup countdown.
- No filesystem check during boot.
- Only local AI runtime discovery runs in the background during those five seconds.
- Runtime rows show installed/running state and detected model count.
- Skip immediately opens login.
- After startup, AI runtime monitoring continues in the background without blocking login/desktop.

## Kausar AI
- Runtime monitor is visible inside Kausar AI.
- Refresh Runtimes button.
- Futuristic original HUD/orb with logo and voice-reactive dots.

## Developer Toolchains
- New Developer Toolchains app.
- Detects Python, C, C++, Node.js, TypeScript, Rust, Go, Java and CMake.
- Explicit real installation uses supported host package managers (apt/dnf/pacman/Homebrew/winget/Chocolatey where available).
- Installation is never silent and may require administrator privileges.

## Code Playground
- Edit source in Python, C, C++, JavaScript, TypeScript, Rust, Go and Java.
- Python and JavaScript execute locally when installed.
- Other languages can be edited/downloaded until their compiler/runtime is installed.

## Full screen
- Bottom taskbar is hidden while fullscreen.
- A small top-center restore button exits fullscreen.
- Existing fullscreen and fallback behavior preserved.

## Preservation
All meaningful v2.5 application files remain in this release; changes are additive.

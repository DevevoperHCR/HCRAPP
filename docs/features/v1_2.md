# DeveloperHCR v1.2 Feature Addendum

This addendum extends the original feature specification without removing prior modules.

## Desktop
- Landscape-first mode is now the normal desktop arrangement.
- Window manager keeps drag, resize, minimize and maximize controls active in landscape.
- Full-screen button is available directly in the taskbar.
- Zoom minus, plus and reset remain direct controls.

## Access
- Free, ₹1, ₹10 and ₹100 plan definitions.
- Future price slots: ₹500, ₹1000, ₹5000.
- Owner/Admin are always full-access/free.
- Free normal users receive a reduced feature set.

## Privacy
- Standard / Private / Private-E2EE-when-configured modes.
- Owner/Admin dashboards expose aggregates, not private chat/search contents.
- No E2EE claim is made without actual encryption/key management.

## Accounts
- Owner creates users and roles.
- Remembered login can persist for 30 days.
- Optional Quick Unlock PIN is OFF by default.
- Example PIN 1234 is not silently enabled.

## Apps
- Web Browser
- Control Panel
- Subscription Center
- Troubleshooting Center
- Expanded HCR Store
- AI Model Manager with explicit Ollama model download
- Kausar AI preserved as the assistant name

## Updates
- Owner repository configuration remains in Settings.
- Optional release check.
- HTTPS asset download.
- Archive path validation.
- Controlled apply/restart instead of silent overwrite of the running process.

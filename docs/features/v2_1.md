# DeveloperHCR v2.1.0-beta — Account & Login Fix

- No hard-coded Owner credentials. First run creates the Owner account interactively.
- Username uniqueness is enforced case-insensitively with a clear "already taken" message.
- Login errors distinguish unknown username, disabled account, and incorrect password.
- Users/Admins can change their own username and password from Settings → Account.
- Owner can change any user's username/password from Owner Dashboard; existing sessions for that target are revoked.
- "Keep me signed in" can persist the secure HTTP-only session for up to 1 year on the device.
- Logging out removes the session; clearing browser/app data can remove it.
- Passwords remain salted PBKDF2 hashes; plaintext passwords are never stored.

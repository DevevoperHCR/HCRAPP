# DeveloperHCR v2.7 — User Signup + Login

- Added self-service **Create User Account / Sign Up** from the login screen.
- Signup creates a `NORMAL_USER` account with `pending` status.
- Owner/Admin approval is required before a new self-signed-up account can log in.
- Username uniqueness is case-insensitive and enforced server-side.
- Passwords are salted PBKDF2 hashes; plaintext passwords are not stored.
- Login now reports a clear pending-approval message for pending accounts.
- Existing Owner setup, Owner/Admin user creation, credential changes, sessions and remember-me login remain unchanged.
- Signup does not create Owner/Admin accounts.

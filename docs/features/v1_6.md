# DeveloperHCR v1.6.0-beta — Feature Notes

### Fixed
- Boot splash hang / infinite-looking startup.
- Startup timeout handling.
- Missing critical-file detection.
- Startup Skip control.
- First-run data/privacy agreement flow.

### Added
- Startup integrity endpoint: `/api/startup/check`
- Agreement endpoints: `/api/agreements/status`, `/api/agreements/accept`
- Consent-gated sync queue: `/api/sync/queue`
- Consent-gated sync flush: `/api/sync/flush`
- Settings → Data & Sync owner controls.

### Privacy boundary
The requested idea of sending “every data” to an admin is intentionally constrained by the agreement: private content, credentials, tokens, private chats, search history and file contents are never sent by this sync path. The user explicitly opts in before any admin telemetry sync is allowed.

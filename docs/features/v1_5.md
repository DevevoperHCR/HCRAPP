# DeveloperHCR v1.5.0-beta — FULL FIX

## Desktop / Mobile
- Landscape-first startup with Screen Orientation API attempt and CSS fallback.
- Boot screen and login follow the same landscape layout on narrow portrait screens.
- Movable, resizable, minimize/maximize/restore windows.
- Full-screen, zoom -/+/reset controls.
- Virtual mouse/cursor taskbar button; pointer-based cursor works on touch-capable browsers when enabled.
- Desktop app icons remain hidden by default; apps are launched from HCR Launcher/taskbar.

## Kausar AI / Jarvis
- Real local AI path remains Ollama/GGUF; no fake responses.
- New animated circular logo orb with rotating ring.
- Voice-reactive dots animate during listening/processing/speaking/generation states.
- Voice status now reports actual TTS/STT/model availability.
- Removed fake voice-model download state.
- TTS/STT test buttons added.
- Safe actions remain allowlisted and dangerous shell operations remain blocked/preview-only.

## Wine / EXE
- Owner/Admin-only real Wine installation button.
- Uses supported official package managers without a shell string.
- Windows is reported as not needing Wine for native EXE files.
- Unsupported platforms fail clearly instead of pretending installation succeeded.
- EXE execution remains confirmation-gated.

## Friends Only
- Friends automatically receive the `friends_trading` practice feature.
- Practice Trading is simulated only: virtual balance/P&L, no real orders or money.
- Owner/Admin remain unrestricted.

## Subscription / Feature Editor
- Owner plan editor supports feature lists.
- `Select all features` button fills the complete current feature catalog for a plan.
- Existing plan prices remain editable.

## Store
- Practice Trading added to HCR Store catalog.
- Existing built-in apps remain preserved.

## Reliability
- Boot timeout/error handling improved so a JavaScript/API failure is visible rather than appearing silently stuck.
- Version: 1.5.0-beta.

# DeveloperHCR 1.3.0-beta — Feature Addendum

## 1. Non-destructive merge
v1.1 and v1.2 are merged. The application source and meaningful runtime data from the older package are retained.

## 2. Desktop
Landscape-first default, fullscreen, movable/resizable/minimize/maximize windows, taskbar zoom, and clean desktop without app icons by default.

## 3. Branding and sound
The supplied DeveloperHCR image is used for boot/login branding. App launcher and taskbar retain unique per-app marks. Sound can be turned off or its volume changed in Settings.

## 4. Owner access
Owner can create users/admins, approve Friends Only, configure Friends credentials, grant subscriptions, set plan prices/features, and grant individual features.

## 5. Admin access
Admin gets dashboard/support/system information and can create normal/access users, but cannot create Owner/Admin or change Owner-only configuration.

## 6. Subscription editor
Owner can edit:
- Plan ID
- Plan name
- INR price
- Feature list
- Future price list

Owner/Admin are always full-access and free. Paid plans are not considered paid without real payment verification.

## 7. Privacy
Dashboards show aggregate usage/security/support information. Private user content is not exposed by those dashboards. E2EE is only claimed after an actual encryption/key-management backend is present.

## 8. HCR Store
The Store contains a broad built-in catalog. Built-in apps open directly. Unpublished catalog items are clearly marked and cannot be falsely installed.

## 9. Updates
Owner configures the repository. The updater checks the latest release and validates HTTPS release assets before a controlled apply/restart.

## 10. Compatibility
EXE/Wine remains permission-gated. Unsupported features report their platform limitation instead of showing fake functionality.

# DeveloperHCR v1.8 Features

## Startup
Quick critical-file integrity check, hard timeout, working Skip, timeout-bounded auth.

## Desktop
Pointer-event move/resize for mouse + touch; launcher-to-desktop drag shortcuts; desktop shortcut persistence.

## Capture
Owner/user-visible training capture settings: quality (low/medium/high) and size (full/1080p/720p/window).

## Reliability
Per-app render failure boundary with Retry.

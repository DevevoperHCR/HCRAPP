# DeveloperHCR v1.9.0-beta

- Boot skip is a synchronous, multi-event escape hatch and a 2.2s hard fallback.
- Startup critical-file check has a 650ms request budget and never blocks login.
- Normal JSON API calls have bounded timeouts.
- Login/auth gate is timeout-bounded and shows a retryable login state instead of a permanent splash.
- Skip button is fixed, blue, bottom-centered and touch-friendly.
- AI Chat auto-discovers the first real local Ollama/GGUF model; it never fabricates a model.
- AI Chat clearly reports when no real local runtime/model is available.

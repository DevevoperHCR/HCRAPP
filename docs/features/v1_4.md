# DeveloperHCR v1.4.0-beta — Expanded Features

## Friends Only Features
- Settings > Friends Only Features is OWNER-managed.
- Named profiles can be added with a display name and password.
- Passwords are salted PBKDF2 hashes; plaintext credentials are not stored.
- A default `Jyotish` profile is created after the first OWNER account is created.
- The requested Jyotish password is represented only by its stored hash.
- Owner can add additional profiles using the UI.

## Owner-only configuration
The following settings cannot be changed by normal users or admins:
- GitHub update owner/repository/channel
- Update enablement/auto-check
- WhatsApp Channel and Group
- Subscription plans, prices and feature lists
- Friends Only policy
- Store source
- EXE support policy

## Updates
1. Owner configures repository.
2. App checks latest release.
3. Owner can publish an update announcement.
4. User sees the message in Update Center.
5. Release asset is downloaded over HTTPS and archive paths are validated.
6. App creates a command for the current DeveloperHCR directory.
7. User can copy that exact command to the DeveloperHCR terminal.
8. `updater.py` backs up source files, preserves `data/`, applies the release and requests restart.

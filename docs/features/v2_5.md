# DeveloperHCR v2.5

- Removed startup file-check from the boot path.
- First launch boot is a short 2-second visual boot; subsequent launches skip the boot automatically.
- Login is shown directly after boot and does not reload the page after successful authentication.
- Landscape-only UI preserved.
- Added post-login local AI runtime observation using the existing provider-status endpoint; it does not claim to detect arbitrary third-party AI software.
- HCR Store now offers Install to Desktop for built-in apps.
- Added 2D Snake, 2D Pong and lightweight 3D cube demo.
- Added extra Settings tabs for Notifications, Accessibility and Workspace quick actions.
- Existing features preserved; no startup check is required before using the app.

# DeveloperHCR v2.0

## Startup
- Immediate mobile-safe Skip button.
- Inline emergency handler prevents cached/broken JavaScript from making Skip inert.
- Skip opens the login UI immediately.
- Login does not wait for settings/auth-status requests before becoming visible.
- 1.5-second automatic escape hatch.
- 450 ms bounded quick checks.
- No-cache headers and asset versioning prevent stale app.js/style.css.

All previous meaningful project files are retained; this release only changes startup robustness.

# DeveloperHCR BETA v1.0.1

- Owner account is never created, replaced, or reset by launcher. Existing Owner DB is preserved.
- Launcher no longer stops on a missing Owner database; browser setup can create the Owner explicitly on a fresh DB.
- Admin bootstrap is fixed to username `admin` and the separately issued Admin password when no Admin exists.
- Android psutil `/proc/stat` PermissionError no longer crashes system-info endpoints.
- Added Friends Only and Subscribers Only temporary guest modes: one active person globally, 10-minute maximum, automatic expiry, and guest-owned data cleanup.
- Guest modes receive Store paid apps free for the active session.
- Added guest access UI on the login screen and countdown/Exit control.
- Preserved paid Store locks for normal Admin accounts and kept Owner free access.
- Version bumped to v1.0.0-beta.1.

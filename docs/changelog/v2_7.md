# v2.7.0-beta

## Added
- User Signup / Create User Account button on the login screen.
- Self-signup API: `/api/auth/signup`.
- Pending approval state for self-registered users.
- Clear login error when a self-registered account is awaiting Owner/Admin approval.

## Security
- Server-side username uniqueness check remains case-insensitive.
- Passwords remain salted PBKDF2 hashes.
- Self-signup can only create NORMAL_USER accounts.

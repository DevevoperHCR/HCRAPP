# DeveloperHCR BETA v1.0.2 — AI / UI Fix Pack

- Fixed Settings crash caused by missing UI-zoom controls (`Cannot set properties of null`).
- Desktop preferences now load from saved settings instead of being hard-coded off.
- Added persistent UI zoom controls and safe null guards.
- Android now uses landscape-first workspace behavior with a fullscreen/orientation request when the user explicitly activates it, plus a CSS fallback.
- AI Chat now discovers the real installed/running model automatically and displays it directly in the model selector.
- AI Chat no longer requires typing a model name every time; it can create the first conversation automatically.
- AI runtime/model refresh is available directly in AI Chat and errors now expose the actual HTTP/provider failure instead of only `Request failed.`.
- Kausar AI voice uses Android/browser Speech Recognition first when available, with the local Vosk/sounddevice path as fallback.
- Kausar AI speech uses browser Speech Synthesis first, with local pyttsx3 fallback.
- Kausar AI animation now uses many moving orbital dots with active listening/processing/speaking states.
- Custom mouse cursor now has a visible movement state/trail-like glow and remains touch-safe.
- Existing Owner database data is preserved; no Owner reset/replacement logic was added.
- Existing Store locks, Friends Only/Subscribers Only, camera, screen capture, and legacy apps remain in the merged catalog.

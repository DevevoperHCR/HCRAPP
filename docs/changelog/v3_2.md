# DeveloperHCR v3.2-beta

## Authentication and startup fixes
- New-user signup is active immediately; no Owner/Admin approval is required.
- Duplicate usernames remain rejected case-insensitively.
- Login errors remain explicit for missing username, missing password, unknown username, wrong password, pending/disabled accounts.
- Admin and Owner login transition no longer waits for desktop initialization.
- Desktop initialization uses short bounded requests and runs in the background after the desktop becomes visible.
- Startup is now a logo-only 2-second loading screen; there is no file-system check in the startup path.
- Countdown is independent of app.js/network and shows 2 -> 1 -> Ready.
- Skip opens Login immediately and never waits for the server.
- AI runtime monitoring can continue after login from the desktop/Kausar layer.
- Static asset cache-busting updated to v3.2.

## Preserved
- Owner/Admin roles and dashboards
- HCR Store and existing apps
- Kausar/Jarvis AI runtime monitoring
- Landscape-only desktop, fullscreen and window management
- Settings, Control Panel, subscriptions, Friends Only, updates, EXE/Wine and developer tools

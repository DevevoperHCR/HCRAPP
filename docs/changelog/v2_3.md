# DeveloperHCR v2.3.0-beta

## Login reliability
- Login handler is wired before background auth/settings checks.
- Added an inline emergency login fallback so the visible login button remains functional even if the main JS bundle is stale or fails.
- Login errors are explicit and Enter submits the form.
- Remember-me session behavior is preserved.

## Control Panel
- Live CPU/RAM/Battery/Network cards.
- Fullscreen, zoom, Settings, Monitor, Network, Files, Troubleshooting and refresh quick actions.
- Security/privacy and session controls.

## Settings
- Fixed the Account tab which previously had no corresponding pane.
- Added Account, Startup, Storage and Performance sections.
- Added UI preference export and desktop-layout reset.
- Settings tab switching is now safe when a pane is unavailable.

## Compatibility
- Existing HCR Store, AI/Kausar, Browser, Games, EXE/Wine, Friends Only, Practice Trading, Subscription, Owner/Admin, Updates, landscape desktop, virtual mouse and prior modules are preserved.

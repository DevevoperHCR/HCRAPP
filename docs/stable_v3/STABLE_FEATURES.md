# DeveloperHCR 3.0 Stable Beta — Feature Improvements

## Reliability
- Real bundled WAV UI/notification sounds with browser-policy-safe fallback.
- Persistent Clock/Timer/Alarm with enable/disable/delete controls.
- Alarm test sound, visual alert, vibration and browser notification when supported.
- Startup check can be skipped once; after the first skip it stays disabled for later launches.
- Settings button is available in every application window title bar.
- Desktop is intentionally organized around File Manager, Recycle Bin and This PC.

## Games
- Dedicated HCR Games Hub remains separate from the normal desktop.
- Game preferences for sound and landscape are saved locally.
- Existing voxel world and 2D/3D games are preserved.

## AI
- GGUF model management remains explicit/manual; no silent downloads.
- GGUF download controls accept HTTPS URLs and explicit .gguf filenames.

## Branding
- HCR uses the existing DeveloperHCR logo asset.
- Stable Beta branding is shown consistently in the launcher/desktop.
- Creator credit is shown as requested.

## Packaging
- No artificial padding.
- No generated Python bytecode or cache.
- Existing project files/features are preserved.

# DeveloperHCR v3.1-beta

- Added Display / Screen Size settings (85%, 100%, 110%, 120%).
- Removed taskbar Zoom controls and replaced them with Screen Size controls.
- Added Display Mode, Taskbar Density, animation and contrast controls.
- Added Control Panel display quick actions and more system-tool shortcuts.
- Landscape-only behavior remains unchanged.
- Screen Size changes the DeveloperHCR UI scale; it does not claim to change the physical device resolution.

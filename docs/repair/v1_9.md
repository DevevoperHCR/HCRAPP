# DeveloperHCR v1.8 — REDMI / Release Notes

- Boot check is intentionally quick (critical files only) and has a working Skip button.
- Login cannot be trapped behind a slow settings/auth request.
- Windows can be moved/resized using mouse or touch.
- Drag an app from HCR Launcher onto the desktop to create a shortcut; double-click opens it. Right-click removes it.
- Settings now include screen-training capture Quality and Size.
- Full diagnostics are optional instead of blocking startup.
- EXE/Wine remains Owner/Admin gated and uses real platform package managers when supported.


## v1.9 boot/chat fixes
- Skip startup is immediate and cannot be blocked by a pending server request.
- Startup check is bounded and optional.
- Login appears even when the local server is slow.
- AI Chat selects an actually detected local model when available; otherwise it explains what must be installed/configured.

# DeveloperHCR v2.0 — Startup/Skip Fix

- Skip is an inline emergency control and does not depend on app.js.
- Clicking/tapping Skip immediately hides boot and reveals Login.
- Login is shown before backend status checks finish.
- Startup quick checks are limited to 450 ms requests and a 1.5 s absolute fallback.
- Static/index/app assets are sent with no-cache headers to prevent stale browser JavaScript.
- Full project scanning remains manual in Troubleshooting.

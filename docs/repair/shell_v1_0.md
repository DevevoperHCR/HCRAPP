# DeveloperHCR BETA v1.0 — Shell Reliability Repair

This additive repair keeps the existing project files and features intact.

## Fixed
- Windows-style Start menu opens from pointer, touch, and keyboard.
- Launcher search filters every installed application by name or app id.
- Search results are real clickable launch controls.
- Desktop shortcuts remain visible across desktop, Android, and landscape layouts.
- Date and time are rendered in the taskbar and refreshed every second.
- Admin recovery is available from the login screen and Settings.
- Admin reset removes all user-facing ADMIN records, including legacy `admin`, while preserving the hidden internal control record and application data.
- Local URL remains `localhost` for the user-facing launcher while the server continues to bind securely to loopback.

## Non-destructive rule
No existing archive entry is intentionally deleted by this repair. The package is rebuilt from the complete previous BETA package and this repair is additive.

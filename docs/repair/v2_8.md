# DeveloperHCR v2.8.0-beta

- Preserves v2.7 signup/login and all previous app modules.
- Adds more local apps: System Information, Downloads, App Installer, Quick Text Viewer, Color Picker, JSON Viewer, Stopwatch.
- HCR Store now also exposes the built-in app catalog with Open / Install to Desktop actions.
- DeveloperHCR logo is shown in boot/login and the launcher button.
- Cache-busted v2.8 static assets prevent stale UI bundles.
- No existing feature is intentionally removed.

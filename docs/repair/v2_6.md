# REDMI — DeveloperHCR v2.6

1. Extract the ZIP.
2. Open the DeveloperHCR folder.
3. Start the normal launcher/server.
4. First startup shows a 5-second countdown and AI runtime monitor.
5. Skip immediately opens Login.
6. Open **Kausar AI** to see currently detected local AI runtimes.
7. Open **Developer Toolchains** to detect/install language runtimes and compilers.
8. Open **Code Playground** to write/download code and run Python/JavaScript when installed.
9. Fullscreen hides the bottom taskbar; use the top-center `⌃` button to restore it.

Automatic toolchain installation requires an available supported OS package manager and may request administrator privileges.

# REDMI v2.1

## Owner login
There is no built-in hard-coded Owner username/password. On first launch, create the Owner username and password on the setup screen.

## Change username/password
Settings → Account lets the signed-in user change their own username/password. Current password is required.

Owner Dashboard → Users & approvals → Username / Password lets the Owner change another user's username/password. Existing sessions for that user are revoked.

## Username rules
Usernames are unique case-insensitively. If a username already exists, creation/change is rejected with a clear message.

## Remember login
The login checkbox keeps the account signed in on that device for up to one year. Logout clears the session.

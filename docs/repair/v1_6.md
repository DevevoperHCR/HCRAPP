# DeveloperHCR:AI Agent — v1.6.0-beta

## Startup / Boot Fix
- Boot splash is now bounded to roughly 1–2 seconds.
- Critical files are checked in parallel.
- A **Skip startup check** button immediately continues to login.
- A slow/dead local server cannot trap the user on the splash screen.
- Startup check reports missing critical files without blocking login.

## Startup Flow
1. DeveloperHCR logo / short boot animation
2. Core + local server check
3. Critical file integrity check
4. Device/desktop preparation
5. Login / first-run owner setup
6. Required agreement screen
7. Windows-like desktop

## Local Data
- SQLite remains the local source of structured app data.
- Browser/local storage is used for supported UI preferences such as zoom/cursor/orientation.
- The application does not silently upload user data.

## Admin Sync Agreement
Admin Sync is **opt-in**.

When enabled by the user agreement:
- Only approved non-sensitive telemetry/diagnostics can be queued.
- Passwords, tokens, API keys, private chats, search history and file contents are excluded.
- Private / Private-E2EE mode blocks Admin Sync.
- Owner configures an HTTPS sync endpoint in Settings → Data & Sync.
- Queued data remains local if the endpoint is unavailable.
- When configured and consented, the app retries queued telemetry while online.

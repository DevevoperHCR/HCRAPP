# DeveloperHCR v2.4.0-beta

- Startup check is a real critical-file verification (exists, readable, non-empty, SHA-256).
- Boot has a deterministic 5-second countdown: 5 → 4 → 3 → 2 → 1.
- Startup never exceeds 5 seconds before opening Login; Skip still opens immediately.
- Landscape-only UI: portrait phones are rotated into a stable landscape canvas.
- Settings orientation selector is landscape-only.

# DeveloperHCR v3.5 Release

This build fixes the login architecture and access presentation without adding separate role-selection buttons.

### Key changes
1. Single credential login screen; role is detected server-side.
2. Owner/Admin accounts can enter directly with their own credentials.
3. Normal users can sign up and immediately log in without approval.
4. Exact login errors are displayed.
5. HCR Store shows the full app catalog; unavailable/paid apps are disabled instead of pretending to be usable.
6. Launcher hides inaccessible apps from normal users.
7. Admin Sync default is ON for non-private diagnostics/approved telemetry.
8. Existing app suite, settings, games, AI/Kausar, developer tools, Wine/EXE, subscriptions, Friends Only and Windows-style desktop are preserved.

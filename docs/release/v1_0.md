# DeveloperHCR:AI Agent — BETA v1.0

- Preserves the existing single Owner account (`Abhimanyu Verma`) and keeps Owner separate from Admin.
- Adds a packaged `admin` account; its password is supplied in the separate credentials TXT.
- Removes the browser Owner-password-reset/forgot-password flow.
- Removes role text from the login screen and uses `admin` only as the username placeholder; the Owner username is not prefilled.
- Compact Remember me; persistent local session is supported.
- Startup integrity verification is performed once per installation and is not rescanned on every server start.
- Android portrait UI is responsive instead of forcibly rotated; PC/Windows remains desktop-oriented.
- Launcher contains only essential apps; the larger catalog remains in HCR Store with descriptions and icons.
- External Store products can be priced individually (examples: ₹1, ₹10, ₹100). Owner access is free.
- Paid Store requests first collect the user's reason and then open the configured WhatsApp group.
- Support email: developerhcr@gmail.com
- Adds visible Camera Monitor with explicit permission and an on-screen active indicator.
- Version: 1.0.0-beta.

# DeveloperHCR v3.3

## Audit
- v3.2 meaningful files preserved; no meaningful source files removed.
- Added Windows-style launcher search.
- Added Environment Setup app.
- Added real package-manager based install-all endpoint.
- Extended toolchain detection: Git, Make, cURL, Wget, OpenSSH.
- Added Settings: Environment, Network, Privacy, Power.
- Added Store catalog entries for personalization, developer tools and system utilities.
- Existing Wine installer remains real and uses supported package managers with explicit user confirmation.

## Internet
Internet is used only when a feature explicitly needs it (browser, model download, updates, package/Wine installation). No silent package download is performed.

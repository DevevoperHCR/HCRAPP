# DeveloperHCR:AI Agent — BETA v1.0.1

## Authentication fix
- Fresh installations ask the user to choose the Owner username/password on the first browser launch.
- Existing Owner accounts are preserved; they are never reset, replaced or recreated by the launcher.
- Owner credentials can be changed later from Settings after verifying the current password.
- Admin remains a separate account and is bootstrapped independently; the terminal now visibly reports the authenticated username/role.

## App restoration
- Restored the complete built-in renderer registry so legacy apps are available again through HCR Store.
- Added/wired AI Models, System Monitor, Games, Trading, Wallpaper/Theme, Environment, Network Tools, JSON Viewer, Editor, Quick Text, Color Picker, Stopwatch, Clipboard, Process Manager, Security Center, Toolchains, Code Playground, Feedback, Friends, Subscriptions, Updates, EXE/Wine, Troubleshooting, About, PDF Viewer, Password Vault and QR & Share.
- Default launcher remains intentionally compact; Store remains the complete catalog.

## Fresh-install data rule
- The distributable ZIP does not overwrite an existing `data/developerhcr.db`.
- A fresh install creates the database automatically and shows the one-time Owner setup.


## BETA v1.0 UI refinement
- Existing working features preserved; no feature was intentionally removed.
- First launch remains 5 seconds.
- Public UI does not display the internal control identity; privileged controls remain background/server-enforced.
- UI styling refined for desktop, mobile, and landscape layouts.
- Store password registry contains hashes/status only; plaintext passwords are not shipped.

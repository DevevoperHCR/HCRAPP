# DeveloperHCR v3.4 Release Notes

## Authentication
- New User opens first and creates an active account immediately.
- User/Admin/Owner login mode buttons are available on the same login screen.
- Invalid username/password errors are explicit.
- Admin/Owner mode rejects a valid password belonging to the wrong role instead of silently entering.
- Duplicate usernames remain case-insensitive.
- Signup requires agreement acceptance.

## Data agreement
- The agreement explains local-first storage and optional Admin Sync.
- Sync remains opt-in.

## Store
- Added catalog entries for Calculator, Screenshot Tool, QR & Share, Notes and Password Vault.

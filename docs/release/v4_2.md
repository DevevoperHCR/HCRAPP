# DeveloperHCR v4.2 — Login, Android and Windows stability fix

- Owner/Admin remain separate roles.
- The packaged Owner database record is preserved; launcher never invents a second Owner.
- `launcher.py` asks only for the Admin username/password when no Admin exists.
- Login is minimal: logo, username, password, Start, Login Troubleshoot, README.txt, Remember me.
- Fixed `/api/agreements/accept` SQLite placeholder mismatch that caused `Internal Server Error`.
- Apps now size correctly on narrow Android screens instead of opening off-screen.
- Launcher/taskbar touch handling is retained and Virtual Mouse/Cursor + Virtual Keyboard shortcuts are available.
- Portrait and landscape layouts are supported without forcing phone rotation by default.

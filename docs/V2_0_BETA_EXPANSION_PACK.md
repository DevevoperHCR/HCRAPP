# DeveloperHCR V2.0 BETA — Expansion Pack

## Added in this build
- Six bundled 1600x900 offline wallpapers: Aurora Lattice, Neon City, Deep Ocean, Solar Flare, Quantum Grid, Crystal Night.
- Wallpaper assets are local and require no external CDN.
- Wallpaper Changer now exposes the new V2.1 visual pack directly in the existing UI.
- Existing games, Store, Security Center, Password Vault, App Lock, Admin Dashboard, Update Center and Feedback/Support are retained.
- Existing app registry and standalone-game architecture remain unchanged.

## Size target
The extracted project is intentionally larger than 20 MB so the release contains a substantial offline asset library instead of artificial filler. The exact extracted size is reported after packaging.
